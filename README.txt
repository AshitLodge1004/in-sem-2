# Teacher Card - React Props

## Run in VS Code

1. Create a React project (if you do not already have one):
   `npm create vite@latest teacher-card -- --template react`
2. Open the project folder in VS Code.
3. Replace the contents of `src/App.jsx` with the code from `App.jsx`.
4. Replace the contents of `src/App.css` with the code from `App.css`.
5. Run:
   `npm install`
   `npm run dev`

The `TeacherCard` component receives `name`, `subject`, and `experience` as props and is reused to display three teacher cards.
